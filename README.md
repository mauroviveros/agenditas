# Agenditas

SaaS de turnos para pymes que venden tiempo. Next.js 16 + Supabase.

```bash
pnpm install
pnpm dev     # http://localhost:3000 · componentes en /dev/componentes
pnpm lint
pnpm test
```

Cómo trabajamos y reglas para agentes: [`AGENTS.md`](AGENTS.md). Producto, diseño, arquitectura, rutas y roadmap: [`docs/`](docs/).
